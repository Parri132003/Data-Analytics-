Dictionary:-
->  dict is a collection of key:value pair
 -> key must be unique and it should be immutable data type
  (int,str,tuple)
-> dict is represented in {}
eg:-  details={1:2,
                'name':'madhu',
                 (1,2):[1,2]}
    print(details)
Accessing:-
dict can access by calling key,we will get value from that key
syntax-->  dict['key']
--> get() method is also used to get the value from the key
syntax:- dict.get(key)
eg:-  data_={ 'name':'madhu',
           'balance':7000,
           'adr':12345667890,
           'pan':'GHNBJNGDB67548M',
           2:[3,4]}
 print(data_['adr'])
 print(data_.get(2))
